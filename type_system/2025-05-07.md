### Binding all universal variables in the typedtree

Richard: there are some OCaml programs that cannot be translated to System F. Leo had an example that made my brain explode. I wonder how this kind of issues is handled by this work.

Here is an example:

```
(* 'a. ('a -> 'a) option *)
# let foo = Some (fun x -> x);;

# let bar =
    (* ('a. 'a -> 'a) option *)
    match foo with
    | None -> 0, "0"
    | Some f -> f 1, f "1";;
val bar : int * string = (1, "1")
```
